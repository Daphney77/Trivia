GOOSE BUZZER
1. Upload the entire goose_buzzer folder to Netlify Drop, GitHub Pages, or another static host.
2. Open the resulting URL on a phone and tap HONK to test.
3. Make a QR code from that hosted URL.
4. The included goose-honk.wav is an offline synthesized honk so the page works immediately.
   To use a real Canada goose recording, replace goose-honk.wav and update the audio src in index.html.
